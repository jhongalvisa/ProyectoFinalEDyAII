# CyberLearn Academy

**CyberLearn Academy** es una plataforma web educativa enfocada en cursos de ciberseguridad. El sistema permite que los estudiantes inicien sesión, consulten cursos, revisen rutas de aprendizaje, visualicen cursos relacionados y se comuniquen con profesores mediante un chat en tiempo real. Además, los profesores pueden acceder a un panel propio para crear cursos y responder mensajes de los estudiantes.

Proyecto desarrollado como entrega final para la asignatura **Estructuras de Datos y Algoritmos II**, usando **React + TypeScript**.
